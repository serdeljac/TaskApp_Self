# Taskly

A ToDo Task App built step by step to learn **React + Vite + TypeScript**.

Read [PROJECT_GUIDE.md](PROJECT_GUIDE.md) before working on this project — it
holds the rules, the design mapping, and the build log.

## Run it

```bash
npm install
```

```bash
npm run dev
```

## Current state

`step-01` — a flat, static dashboard page. No state, no interactivity yet.
